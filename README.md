# xanderpico

Alex Pico’s personal site: experimental science, scientific software, and new directions in AI.

Custom domain: https://xanderpico.com/

This repository contains only the public static site. Research notes and editorial working material are not included.

## View locally

Open `index.html` in a browser, or serve this directory with `python3 -m http.server 8000`.

## Hosting

GitHub Pages serves `main` from the repository root. All site assets are local; no JavaScript, analytics, cookies, external fonts, or package installation are required.

The publication page is a selected bibliography, not a complete publication record. Project descriptions distinguish concepts and work in development from published outputs.
